# Travel desk - finance operations

Repository for the finance desk's corporate travel-claim intake batches.

- Monthly intake batches are filed on `claims-YYYY-MM` branches, with the documents under `intake/`, the batch register in `tracking/batch_register.csv`, and the close-out rules in `batch_notes.md`.
- Approved summaries are stored under `summaries/`.
- The default branch holds the desk's documentation and the most recent approved summaries.
